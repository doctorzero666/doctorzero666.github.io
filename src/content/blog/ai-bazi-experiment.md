最近秋招真的烦。天天闷在家里，连面试都见不到真人。国庆假期投出去的简历，也迟迟等不到回应。😮‍💨

明天会不会好一点？我不知道。想来想去，开始惦记老祖宗那句“一命二运三风水”。可刚毕业，手头不宽裕，实在舍不得花钱请大师，干脆让 AI 试试。

原本只是想找个情绪出口，最后却做了非常复杂的对照实验，涉及到五个模型，六种条件。最让我没想到的是：**没有额外提供出生资料和命盘，几个模型就已经能答对四成左右的题。**

那它们究竟是在算命，还是用别的办法答对了题？要说清这个问题，得先回到一个最基础的问题：命理师的水平，到底该怎么测？

## 先别急着算，怎么判断算得准？

如果直接问 AI“我以后过得好不好”，它会洋洋洒洒写上一大段，可能越看还越觉得有道理。可要判断它究竟算得准不准，就很难了。

我需要一份有题目、有选项、有参考答案的试卷。在 AI 评测里，这叫 benchmark，也就是用来衡量模型表现的测试集。

找了一圈，还真有这样的题库。公开的算命比赛题目中，有一类会给出某个人的出生资料，再让参赛者判断他过去经历过什么。

例如，一个人早年在北京生活，后来去了厦门工作，这次搬迁发生在哪个年龄段？四个选项是：27 至 31 岁、32 至 36 岁、37 至 41 岁、42 至 46 岁。

这样就具体多了。必须选定一个答案，再与参考答案核对，不能靠模棱两可的解释把话圆回来。

不过，我无法向当事人逐一核实这些经历，只能按照题库的参考答案评分。模型在这类题上得分高，也不等于它能够预测尚未发生的未来。

前期我看过 fate-bench 和 BaziQA 的不同版本。这轮正式实验选定一个题库版本，排除资料缺失的题目和部分出生资料有冲突的命例，最后留下 **48 位命主、226 道题**。下文的成绩都来自这批题，具体筛选过程放在文末。

## 为什么我要设计六组实验？

研究 AI 算命方案时，我注意到两种做法：一种是提前排好命盘交给模型，另一种是把人类总结的分析步骤告诉它。

这很符合直觉：资料更齐全，方法讲得更清楚，应该能帮助它答对更多题。就像考试能带上一张cheat sheet，总觉得会更有把握。

但假设 AI 答对了 40% 的题，这个分数就能说明它会算命吗？题干可能藏着线索，选项之间可能有规律，模型也可能接触过相关公开材料。如果把生日、命盘和教程一次性给齐，我就很难知道它靠什么答对了题。

**所以，我需要一组只给题目和选项的测试作参照，再看命理资料究竟能帮它多答对多少题。**

出生资料与现成命盘也要分开测。模型拿到生日后，可能会自己尝试排盘；如果这一步容易出错，直接给它排好的盘，或许能改善成绩。分开比较，才能知道是哪一步起了作用。

至于分析方法，我用的是一组八字 Skill 提示材料，也就是指导模型分析八字的提示词和参考资料。材料包含 Skill 主文件、提示模板和天干地支参考资料，拼接后作为提示文本提供给模型。在三种资料条件下分别加入同一组材料，就能观察：它是否需要配合出生资料或命盘，才有可能帮上忙。本次没有运行完整的配套流程。

六组条件如下：

| 条件 | 题目与选项 | 出生资料 | 排好的命盘 | Skill 提示材料 |
|---|---|---|---|---|
| A | 有 | 无 | 无 | 无 |
| B | 有 | 有 | 无 | 无 |
| C | 有 | 有 | 有 | 无 |
| D | 有 | 无 | 无 | 有 |
| E | 有 | 有 | 无 | 有 |
| F | 有 | 有 | 有 | 有 |

每个模型都在六种条件下各答三轮。我只调整每次答题时提供的材料，没有训练模型，也没有更新它的参数。主要对比和严格评分规则在正式开跑前就已经确定并保存。去除代码围栏后的评分属于事后分析，附加对比也作为补充单独报告。

还有一个细节：有些模型会因为资料不足而拒答。所以，这轮测试要求它每题都选一个答案，同时单独回答：“如果允许，你会不会放弃这道题？”这项记录后来也派上了用场。

## 发现一：没有额外命理资料，也能答对四成

先看只给题目和选项的 A 组。GPT 6-sol 的正确率是 **41.7%**，Fable 是 **41.9%**，GPT 5.6-sol 是 **40.3%**。

这套题既有四选一，也有五选一。如果每题都随机猜，而且每个选项被选中的概率相同，期望正确率约为 **24.5%**。

![A 组：只给题目和选项，三个模型达到约四成。](/blog/ai-bazi-experiment/02-group-A.png)

*亲测｜条形表示按预先规定的严格规则计算的成绩。Opus 的部分答卷因外层格式标记被计零，空心菱形表示去除这些标记后重新评分的结果。*

我原本想看命理资料能帮模型提高多少分，没想到，在补充这些资料之前，它们就已经拿到了相当一部分分数。

当然，“只给题目”不等于没有任何关于命主的信息。部分题干本身就包含年份、性别等线索。模型可能利用了这些线索，也可能凭常识推断，或者接触过相关公开材料。这轮实验还无法区分这些可能性。

但这个参照组已经提醒我：**答对算命题，和依靠命盘答对算命题，不能直接画等号。**

那么，把资料补齐以后呢？

## 发现二：资料和教程补齐，没有测到可靠提升

以 GPT 6-sol 为例：只给题目时是 41.7%，加上出生资料后是 44.2%，再加现成命盘后是 43.2%。

Fable 则依次是 41.9%、41.4%、41.0%。

这些成绩有升有降，没有出现我预想中“资料越完整，成绩越好”的变化。

但多答对几道题，也可能只是偶然。我需要比较的是：面对同一位命主的同一批题，同一个模型在增加资料后，究竟多答对了多少。

为此，我把同一轮中的两组答题结果配对比较，再计算分差的 95% 区间。下图中的点表示两组成绩相差多少，横线表示统计区间。横线跨过零，就说明这批数据还不足以确定，加上资料究竟让模型答得更准了，还是更差了。

![出生资料与命盘的增益：五个模型的各项区间均跨过零。](/blog/ai-bazi-experiment/08-information.png)

*亲测｜C−A 比较补齐出生资料和命盘前后的成绩，C−B 比较提供现成命盘前后的成绩。B−A 单独比较出生资料带来的变化。*

对这五个模型来说，无论是补齐出生资料和命盘，还是在已有出生资料的基础上再提供现成命盘，这次都没有测到可靠提升。

那给它一套具体的分析步骤呢？

把三种资料条件下“加 Skill”和“不加 Skill”的成绩分别比较，对应的就是 D 与 A、E 与 B、F 与 C。

![加入 Skill 后的分差：资料齐全时，五个模型的区间均跨过零。](/blog/ai-bazi-experiment/09-skill.png)

*亲测｜图中的 Skill 指前述三份文件拼接成的提示材料。三项对比分别对应只有题目、加出生资料、资料与命盘齐全时的效果。主要对比与附加分析的划分，以及统计处理方法，见文末。*

**资料齐全以后，再加这组 Skill 提示材料，同样没有测到可靠的准确率提升。**

不过，有一处变化需要单独解释：Opus 在 E 组的成绩比 B 组高出约 10 个百分点，看起来进步很大。

检查答卷后，我发现它有时会在答案外面加上 Markdown 代码围栏，也就是一层格式标记。按照事先规定的评分规则，这样的答卷整份计零。加入 Skill 后，它更少犯这类格式错误了。

我保留了原来的严格评分结果，又去掉这层格式标记，重新评了一次分。同一批答卷，两组的分差就从 **+10.03 个百分点变成 +1.77**，后者的区间跨过零。完整成绩见文末总览。

所以，这个看起来很大的提升，有一部分来自格式扣分减少，不能全算在“算命能力提高”上。

这次没有测到预期中的可靠提升，但样本毕竟有限，还不能据此断言出生资料和命盘毫无作用。对这份 Skill 的观察，也不能直接套用到其他 Skill 上。

## 发现三：它更愿意回答了，却没有相应地答得更准

看完成绩，我又回头检查了模型对“是否愿意回答”的表态。

DeepSeek 只拿到题目时，自报会弃权的比例约为 **95.9%**。加上出生资料后，这个比例降到了约 **3.6%**。

但准确率只是从 **35.3% 变成 35.4%**。

![六组自报弃权比例：DeepSeek 加入出生资料后明显下降。](/blog/ai-bazi-experiment/11-abstention.png)

*亲测描述｜所有题都被要求作答，图中统计的是模型表示“如果允许就会弃权”的比例，不是实际拒答率，也不能当作客观置信度。只统计能够评分且有弃权标志的题次，未做显著性检验。*

这个反差让我印象很深。出生资料补上以后，它不再像之前那样频繁地表示想弃权，但答对的比例几乎没有变化。

想到自己最初是想找 AI 算命，这个结果就更值得记住了。我希望它给我一个明确的答案，可**愿意回答，不等于回答准确。**

## 人觉得严密的方法，AI 就一定用得上吗？

一开始，我想知道“AI 算得多准”。做到后来，我更想知道：“它到底是怎么答对这些题的？”单凭这些分数，我还无法判断它有没有按照命理方法进行推理。

从生日排出命盘，再按照一套方法分析，在我看来环环相扣。我很自然地认为，把这套流程交给 AI，它就应该做得更好。结果却让我开始怀疑：**人类眼中的“重要信息”和“严密的推理逻辑”，对 AI 来说，真的同样重要吗？**

这还不足以说明人类的方法不适合 AI。毕竟，我既没有验证这套方法对人是否有效，也没有真正训练模型。不过，这个疑问让我联想到了围棋。

早期的 AlphaGo 学习了人类棋谱，再通过自我对弈提高水平。后来的 AlphaGo Zero 没有使用人类棋谱训练，而是结合神经网络与搜索，从自我对弈的结果中不断改进。它会根据已经学到的判断继续探索，并不是把所有棋局都遍历一遍。[来源：AlphaGo 原始论文](https://www.nature.com/articles/nature16961)、[DeepMind 官方介绍](https://deepmind.google/blog/alphago-zero-starting-from-scratch/)

这与我给现有模型增加提示材料，是两种不同的过程。围棋案例不能解释这次算命实验的结果，但它让我想到：经验可以从前人那里学习，也可以在自己的尝试和反馈中积累。

## 从一个人的弯路，到后来者的经验

我是一个工科生，学过很多用发现者名字命名的科学定律。课堂上花几分钟就能记下的公式，背后可能是许多人一生的探索。我们能从前人的成果出发，是因为他们已经替我们走过了一些弯路。

从个体的角度看，我们当然希望少犯错。选一个专业、进入一个行业、开始一段关系，都需要投入真实的时间和精力。等到终于明白哪里出了问题，几年可能已经过去了。

所以我们学习前人的经验，希望在作出选择之前，尽可能知道什么值得尝试，什么应该避开。

想到这里，我突然明白自己为什么想算命了。那些关于命运的解释，似乎能让我相信：眼前的不顺只是人生中的某个阶段，往后还有转机。我想提前知道答案，因为每一次尝试，都要由自己承担代价。

这样的解释或许能带来安慰，至于它能否准确预测人生，还需要证据。

如果借用 AI 工程的语言作一个比喻，八字就像一组描述出生时刻的“初始参数”。但人的一生还会遇见许多人，作出许多选择，经历许多无法预料的事。这些后来发生的事情，也会不断改变我们人生的走向。

那么，要让后来的人理解一段人生，只留下最初的条件和最后的结果，显然还不够。

## 把走过的路留下来

我们还需要记录：当时遇到了什么，为什么那样选择，后来发生了什么，又因此作出了哪些调整。这样，一次经历才有机会成为别人能够参考的“上下文”。

把视角从个人拉远到文明，前人的经验总有回答不了的新问题，需要有人继续探索。有人找到了可行的办法，有人发现此路不通。只要这些过程被理解、被留下，后来的尝试就多了一点依据。

**从个体看，我们通过学习经验减少试错；从文明看，我们又通过不断的试错增加经验。**

今天帮助我避开弯路的知识，可能是另一个人付出了不少代价才换来的。而我今天为解开一个疑问所做的尝试，也可能留下几条线索，让后来者不必再从头摸索。

想到古人修史、后人读史，这还真有一点“文明级别的 Harness 工程”的意味：把经历和反馈保存、整理好，供后来的探索使用。在这个比喻里，一份个人记录也能成为其中的一小部分。

把这次实验的设计、结果和疑问写下来，也就为后来者留下了继续核对和探索的起点。

这是我的第一篇推文，谢谢你读到这里，也欢迎关注后续的分享。

也希望你开始记录自己的生活。不必等到有了好结果，即使不公开，也可以留给未来的自己。

这次实验还没有告诉我未来会怎样，我能做的，是继续生活、继续尝试，认真记录。

**可能我今天留下的困顿与思索，可以让你明日走同一段路时，少一些荆棘。**

### 必要说明

- 题库从固定版本的 295 题筛选为 48 位命主、226 题。每个模型每组共 678 个题次，来自同一批题重复三轮，不能当作独立的新题。其中 205 题四选一、21 题五选一，均匀随机猜测的期望正确率为 24.54%。
- 准确率按全部纳入题次计算，格式失败和截断等按严格规则计零。Opus 的 864 份答卷中有 199 份受到代码围栏影响，去围栏评分仅作事后补充。

- 161 题的答案标为官方来源，65 题标为第三方转录。这只是题库的来源标注。人生经历未向当事人逐一查证，命盘未独立重排，资料冲突也未全部排除。
- 图中模型分别为 GPT-6 Sol、Claude Fable 5.1、GPT-5.6 Sol、DeepSeek-V4.1-Flash 和 Claude Opus 5.5。两款 GPT 分别请求 `gpt-6-sol`、`gpt-5.6-sol`，运行记录没有返回实际服务型号。
- 没有测到可靠提升，不等于效果为零，也不能据此确定模型如何推理。题干线索、常识和公开材料的影响仍待验证；后半篇关于八字、文明和人生的讨论属于作者联想。
